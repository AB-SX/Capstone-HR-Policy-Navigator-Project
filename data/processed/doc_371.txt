Git internals
Support Engineers troubleshoot Git operations daily: push/pull failures, repository corruption,
merge conflicts, LFS issues and server-side hooks. Understanding Git internals (packfiles, refs,
objects, transfer protocols) is directly applicable.

Containers and Docker
GitLab Runner uses Docker executors, GitLab.com and Dedicated uses Kubernetes, and many
Self-Managed customers use container-based deployments. Understanding container
fundamentals is important for debugging CI/CD job failures, registry issues and deployment
problems.

configuration, certificate issues and resource limits.
