Go
Gitaly (the Git RPC service) and GitLab Runner are both written in Go. Support Engineers
encounter Go stack traces in Gitaly logs and Runner debug output. Being able to read Go code
helps with:
Understanding Gitaly error messages and behaviour
Debugging GitLab Runner executor issues
Reading and understanding Gitaly and Runner source code when investigating bugs

PostgreSQL
PostgreSQL is GitLab’s primary datastore. Support Engineers regularly help customers with
database performance issues, migration failures, replication problems, Patroni/PgBouncer
configuration and backup/restore procedures.
