When: Within 48 hours of each activity.

Finding the right template
When in doubt:
If you’re planning your quarter → Quarterly Planning Template + Budget Request
Template.
If you’re planning an event → Event Planning Checklist + Event Announcement
Template.
If you’re working with your Executive Sponsor → Executive Sponsor Meeting Agenda.
If you’re tracking work/influence → Shared Activity Tracker + Quarterly Report
Template + Impact Measurement Tracker.
If you’re new to the role → New Lead Onboarding Checklist.
The internal Templates Index in the TMxG Leaders Resource Hub provides the canonical list of
template files, owners, and links and should be kept up‑to‑date.
